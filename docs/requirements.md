# User Requirements
---
**As a** Terraform Developer
**I want to be able to** view the terraform documentation without an internet connection
**So I can** work uninterrupted, even if my connection is poor
---
**As a** Terraform developer
**I want to be able to** view the documentation in the command line
**So I can** avoid clogging up my browser with tabs of different resources
---
**As a** TFDocs user
**I want to be able to** immediately jump to the provider page I want
**So I can** save time and avoid the welcome page
---
**As a** User
**I want to be able to** install the program on multiple platforms
**So I can** use the tool I'm familiar with wherever I choose
---
