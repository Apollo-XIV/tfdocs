TFDocs

Terraform documentation viewer for the command-line.

TFDocs is a command-line application that makes it easy to view the Terraform documentation. TFDocs provides an intuitive GUI containing all of the available information from your local directory, storing it in a local cache so it can be used offline.

Installation

pipx install tfdocs-cli

or

curl tfdocs.crease.sh/install | bash
