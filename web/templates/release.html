TFDocs is a command-line application that makes it easy to view the Terraform documentation. TFDocs provides an intuitive GUI containing all of the available information from your local directory, storing it in a local cache so it can be used offline.

Download AppImage (Linux Only)

After downloading the AppImage, it needs to be moved to a location on your user's PATH. Check your distribution's documentation for more information on manually installing an executable.

mv ~/Downloads/tfdocs.AppImage /usr/local/bin

Non-Linux Installation

You can install TFDocs on any platform that supports Python. TFDocs is published on PyPI, meaning that it can be installed via pip:

Virtual Environment install: pip install tfdocs-cli

User-wide install: pip install -U tfdocs-cli

or most-easily with pipx, a package manager for python applications.

pipx install tfdocs-cli=={{version}}
